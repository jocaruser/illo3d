# v3.2.1

## Deploys work again

Releases since v3.1.3 were created but never reached GitHub Pages: the deploy workflow installed
whatever pnpm was newest, and pnpm 12 rejected the lockfile. The live site was still serving
v3.0.0. This release ships everything since v3.0.0 to the site.

- Deploy now ships the exact build CI's `build` check runs on every PR (same Docker image, same
  pinned pnpm), so a build that would break deploy fails the PR instead
- The Release run calls the deploy and fails when the deploy fails, instead of reporting success
  while the deploy fails in a separate run
- `make toolchain` (part of CI and `make quality-gate`) fails when a Dockerfile or workflow drifts
  from the pnpm version pinned in `package.json`
- The production build now bundles production React; the CI build had been bundling
  development React because the container sets `NODE_ENV=development`

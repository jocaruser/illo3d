# v3.2.0

## Save preview

Pressing **Review** in the workbook toolbar no longer writes immediately behind a blocking
overlay. It opens a review of what saving will do, before anything is written, and shows the
number of pending uploads in parentheses when there are changes (e.g. **Review (3)**):

- A sheet-by-sheet card list (the migration wizard's step cards, made selectable) shows where
  the unsaved changes live — "3 rows changed" at a glance, per sheet
- The main view is a split side-by-side diff of every modified row: field by field, old value
  and new value side by side, old in red and new in green, built from the audit entries the
  change already recorded
- Entity references in the diff are live links — the changed row links to its page, and fields
  that point at another entity (client, job, tag…) link the way they do everywhere else
- Unchanged fields are hidden by default; a toggle shows the full row
- Any changed field of an edited row can be **reverted individually** — the revert is itself
  audit-logged, so the history stays honest
- **Save all** writes the whole workbook exactly as before, but progress now plays out on the
  same cards (saving → saved, red on failure) instead of a modal overlay; the review stays
  open afterwards, every card green
- **Discard all** on the save review page reloads from storage after the usual confirmation —
  it is now the only discard entry point; the navbar no longer has a separate **Refresh**
  control

## Under the hood

- The workbook store now tracks how much of the audit log has been persisted; the unsaved tail
  of `audit_log` is what drives the preview's diff
- Sheet icons and labels are shared between the migration wizard and the save preview

# Release 3.1.3

## Migration wizard

- Upgrades now run entirely in memory until the shop owner clicks **Confirm and close**.
- Optional pre-upgrade backups are written during the backup step; failed runs no longer leave a `.migration` working-copy folder on local shops.
- Google Drive and local CSV shops share the same confirm-before-persist contract (ADR-0012).

## Job detail piece lifecycle

- Soft-deleted and archived pieces stay visible on the job detail pieces table with strikethrough styling, lifecycle actions, and read-only material lines when expanded.
- Added `LifecycleService.restorePiece` for un-archiving pieces without cascading to material lines.
- Landed `specs/jobs/details/pieces-table.spec.md` from the reconciliation corpus.

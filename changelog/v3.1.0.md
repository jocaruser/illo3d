# v3.1.0

The behaviour specs are now a public wiki.

## Specs wiki

- Read the specs at <https://jocaruser.github.io/github-md-live-wiki/> — searchable, with
  sidebar navigation, dark mode, on-device automatic translation (Español and more), and links
  back to every file on GitHub
- The wiki renders the `.md` files **straight from GitHub at view time**: spec changes merged
  to `main` are visible immediately, with no release and no deployment — from this repository
  or anywhere else
- A version menu shows the specs at **any release, branch head, or commit id** — pick a release
  to read the frozen record, a branch to review specs in flight, or paste a commit id
- The wiki engine is its own free, MIT-licensed project
  ([jocaruser/github-md-live-wiki](https://github.com/jocaruser/github-md-live-wiki)), built to
  this repository's engineering standards; its GitHub Pages hosts the live instance
- For contributors: `make wiki` runs the same wiki locally on port 5176 (one Compose service
  pulling the engine's image), with your working-tree `specs/` offered as a **local** entry in
  the version menu

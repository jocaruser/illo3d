# v3.1.0

The behaviour specs are now a public wiki.

## Specs wiki

- Read the specs at <https://jocaruser.github.io/illo3d/specs/> — searchable, with sidebar
  navigation, dark mode, per-page "last updated" dates and an edit-on-GitHub link
- Spec changes merged to `main` go live automatically; no release needed
- A version menu offers a frozen snapshot of the specs for every release from this one onward,
  alongside the always-current **latest**
- Links that point outside the specs tree (for example `schema.dbml`) open the referenced file
  on GitHub at the matching version
- For contributors: `make wiki-dev` serves the wiki locally on port 5176 and hot-reloads as
  spec files are edited

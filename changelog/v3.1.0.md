# v3.1.0

The behaviour specs are now a public wiki.

## Specs wiki

- Read the specs at <https://jocaruser.github.io/illo3d/specs/> — searchable, with sidebar
  navigation, dark mode, and links back to every file on GitHub
- The wiki renders the `.md` files **straight from GitHub at view time**: spec changes merged
  to `main` are visible immediately, with no release and no deployment
- A version menu shows the specs at **any release, branch head, or commit id** — pick a release
  to read the frozen record, a branch to review specs in flight, or paste a commit id
- The wiki engine lives in its own repository
  ([jocaruser/specs-wiki](https://github.com/jocaruser/specs-wiki)) and reaches illo3d as a
  pinned Docker image; engine bugfixes ship there, never here
- For contributors: `make wiki` serves the wiki on port 5176 with your working-tree `specs/`
  offered as a **local** entry in the version menu

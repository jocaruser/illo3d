# v2.0.1

## Audit Log Data Loading

- Added `matrixToAuditEntries()` parser to load audit data from CSV sheets
- Added `useSnapshotAuditEntries()` hook for efficient audit log data access
- Audit log page now renders actual audit entries in the table
- Entries sorted by timestamp descending (newest first), with `id` as tiebreaker
- Malformed rows (missing `id` or `timestamp`) are rendered with error formatting instead of being silently discarded
- Empty state persists when no audit entries exist

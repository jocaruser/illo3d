# v3.0.2

## Dev server screen capture

Vite dev and preview servers now accept any Host header inside the sandboxed
Compose network, so automated QA screen captures through the runner's Docker
daemon hostname show the real application instead of Vite's "Blocked request"
page.

## Parent detail lifecycle alignment (QUEUE-L02)

- Added `specs/shared/lifecycle.spec.md` as the page-focused authority for archive-then-soft-delete on job, client, and inventory detail routes.
- Archived parent detail pages are read-only with un-archive and soft delete only; active pages offer edit and archive without soft delete until archived.
- Soft-deleted parents continue to show the standard not-found card at their own URL.
- Archived inventory items remain reachable at their detail URL instead of showing not-found.

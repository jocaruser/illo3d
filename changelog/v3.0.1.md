# v3.0.1

## Developer experience

- `make wiki` browses the behaviour specs in a local **Live Wiki** on
  <http://localhost:5176> — a single Compose service that pulls the
  `ghcr.io/jocaruser/github-md-live-wiki` image. The wiki reads `specs/` straight
  from GitHub, so it needs no build, and its version menu shows the specs at any
  release, branch, or commit. No application behaviour changed.

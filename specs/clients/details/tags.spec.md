# Tags

Tags are shared labels —
one pool for the whole shop,
attachable to clients and jobs alike:
this file owns the mechanics,
and a job's tags section behaves identically.

The section shows the attached tags as chips,
each removable in place.
Adding is one box — "Type to search or create…" —
which searches the pool as you type:

- picking an existing tag attaches it;
- a name matching an existing tag, in any capitalisation,
  reuses that tag — the pool never gains duplicates;
- a genuinely new name creates the tag and attaches it.

Attaching the same tag twice is quietly refused.
Tags surface wherever their owner does:
in list tooltips, and in [search](../../search.spec.md).

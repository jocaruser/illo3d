# Dashboard — recent transactions

The five newest movements of money, newest first,
each with its description, date and amount
(income green, spending red).
"View all" opens the transactions page.

A movement's description links to what explains it:
a job's income links to the job,
a purchase with materials links to its own details page,
anything else is plain text —
[the ledger's own rule](../transactions/list.spec.md).
